Git Practice Repository

About

This repository is for learning and practising Git and GitHub.

It contains files created during practical exercises to understand version control and collaborative software development.

Topics Covered

- Git installation and configuration
- Initializing repositories using "git init"
- Tracking changes using "git add"
- Saving changes using "git commit"
- Viewing commit history using "git log"
- Connecting local repositories to GitHub
- Uploading changes using "git push"
- Downloading updates using "git pull"
- Creating and switching branches
- Merging branches
- Resolving merge conflicts

Tools Used

- Git
- GitHub
- Termux
- Nano text editor

Purpose

The purpose of this project is to develop practical Git and GitHub skills that will be useful when working on individual and group software development projects.
